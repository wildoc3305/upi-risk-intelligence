# Data

This directory is reserved for datasets used by the UPI Risk Intelligence pipeline.

## Data policy

Do not commit private, real customer, bank, UPI, or personally identifiable transaction data.

Use:
- public datasets with compatible licensing, or
- synthetic/anonymized project data.

## Planned layout

- `raw/` — source data kept locally
- `processed/` — outputs from preprocessing
- project notes and schema documentation live alongside the dataset workflow
